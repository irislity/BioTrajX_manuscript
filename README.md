# BioTrajX manuscript code

Tidied snapshot of the manuscript analysis/figure-generation code, split out
from the working repo.

## Layout

```
manuscript/
  scripts/
    main/        Figure 1 + DOE schematic (main text)
    synthetic/   Synthetic-fixture visualization (Figures S1-S7)
    real/        Real-dataset TI + DOE pipelines (see below)
    setup/       One-time dependency bootstrap (install_deps.R)
  assembly/      Figure assembly (PDF layout/compositing) + layout configs
```

### `manuscript/scripts/real/`

| Dataset | Preprocessing | Run TI methods | DOE / figure |
|---|---|---|---|
| LCMV time course (GSE131847) | raw counts already embedded in `data/GSE131847_seu.rds`; `GSE131847_preprocessing.R` documents the original raw-data reconstruction for reference only | `run_ti_gse131847.R` | `make_figure_S8.R` |
| CD8 exhaustion (GSE164690) | `cd8_processing/01_load.R` → `02_preprocess.R` → `03_ProjecTILs_CytoTRACE.R` | `run_ti_cd8t.R` | `make_figure_S9.R` |
| Stem cell differentiation (branched) | already-processed input (`data/stem_cell.rds`); no raw-preprocessing script needed | `run_ti_stemcell.R` | `make_figure_S10.R` |
| Root Selection | — | (uses `run_ti_methods.R` directly) | `make_figure_S11.R` |

- `run_ti_methods.R` is the shared library (all 8 TI methods) sourced by
  every `run_ti_*.R` script above. It also sources
  `manuscript/scripts/synthetic/helper-fixtures.R` for its synthetic-fixture
  self-checks.
- `environment.yml` (repo root) is the conda env for the Python-based methods
  (PAGA-DPT, Palantir) invoked via `reticulate`, and also covers the
  figure-assembly scripts' Python dependencies (see [Dependencies](#dependencies)
  below).

## Data provenance

- **GSE131847** (LCMV time-course CD8 T cells, naive → d90 post-infection):
  raw counts are already embedded in the provided `data/GSE131847_seu.rds` —
  nothing needs to be re-downloaded to reproduce Figure S8.
  `manuscript/scripts/real/GSE131847_preprocessing.R` documents how the
  Seurat object was originally built from the raw per-day UMI tables,
  adapted from `trajectory_analysis.R` published alongside Hudson & Wieland,
  *"Technology meets TILs: Deciphering T cell function in the -omics era"*
  (2023), Mendeley Data DOI [10.17632/3dvt79c7yt.1](https://doi.org/10.17632/3dvt79c7yt.1)
  — kept for reference only, not required to run this pipeline.
- **GSE164690** (CD8+ T cell exhaustion, PBL + CD45+ tumor-infiltrate
  samples, head & neck cancer): raw 10x matrices at GEO accession
  [GSE164690](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE164690).
  `cd8_processing/01_load.R → 02_preprocess.R → 03_ProjecTILs_CytoTRACE.R`
  reconstruct `data/cd8t.rds` from `data/GSE164690_RAW/`.
- **Stem cell** (`data/stem_cell.rds`): the ageing haematopoietic stem cell
  dataset, originally generated by Kowalczyk et al. 2015, obtained as a
  preprocessed/batch-corrected expression matrix from the CytoTRACE website
  (Gulati et al. 2020). Comprises long-term HSCs, short-term HSCs, and
  multipotent progenitors isolated from young and old mice. No
  raw-preprocessing script exists or is needed — `data/stem_cell.rds` is
  already the analysis-ready input.

## Dependencies

### R

- **BioTrajX package**: install from the sibling package-only repo
  (`remotes::install_github("irislity/BioTrajX")`) — not included inside
  this folder.
- **CRAN packages**: `renv::restore()` using the checked-in `renv.lock`.
- **Bioconductor / GitHub-only packages** (not capturable by
  `renv::restore()` alone — renv snapshots exact source hashes from a real
  install, so these have to actually be installed once): run
  `Rscript manuscript/scripts/setup/install_deps.R`, then
  `renv::snapshot()` to lock them in for next time. See that script for the
  exact package list and sources (SingleCellExperiment, slingshot, destiny,
  SCORPIUS, TSCAN, monocle3, CytoTRACE, ProjecTILs, fgsea,
  ggh4x).
- **`data/`**: not included.

### Python

Single conda environment (`environment.yml` at the repo root) covers both
the `reticulate`-invoked TI methods and the figure-assembly scripts:

```
conda env create -f environment.yml
conda activate biotrajx_ti
```

In R, point `reticulate` at it before running `run_ti_methods.R`:
`reticulate::use_condaenv("biotrajx_ti")` (or set `RETICULATE_CONDAENV`).
